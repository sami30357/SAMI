Dual-anchor comparables forecaster for GTA VI's launch-day Twitch viewers, hour by hour. It learns the intraday shape from past big launch days and scales it by the observed hour-1 print, forecasting hours 2-24 as five quantiles each.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output python3 main.py
```
